# Ibrahim's Personal Portfolio

A responsive single-page portfolio showcasing my projects, testimonials, and contact information.

## Live Demo

[View My Portfolio](https://ibross10.github.io/Ib-portfolio/)

## Features

- Navigation links to different sections of the page.
- Testimonials rendered dynamically from a JavaScript object using a loop.
- Project cards generated dynamically from a JavaScript array of objects.
- Links to the GitHub repositories for my projects.
- Contact section with email and GitHub links.
- Copy Email button using JavaScript and the Clipboard API.
- Responsive layout for different screen sizes.
- Keyboard-focus styling to improve accessibility.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Ibross10/Ib-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Ib-portfolio
   ```

3. Open `index.html` in your browser, or use the VS Code Live Server extension.
