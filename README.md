
# Ibrahim's Personal Portfolio

A responsive single-page portfolio showcasing my projects, testimonials, and contact information.

## Live Demo

Coming soon — the website will be published using GitHub Pages.

## Features

- Navigation links to page sections.
- Testimonials rendered dynamically from a JavaScript object using a loop.
- Project cards generated from a JavaScript array of objects.
- Contact section with email and GitHub links.
- Responsive layout for different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## How to Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## What I Learned

I learned how to structure a single-page website using HTML and style it with CSS, including responsive layouts.

I also learned how to use JavaScript objects, arrays, and loops to dynamically create and display content on a webpage.
